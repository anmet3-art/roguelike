# Roguelike

Консольный roguelike на C++: исследуй уровни, сражайся с врагами, открывай сундуки, собирай зелья и найди лестницу вниз. Учебный проект, написанный с нуля на C++17 (ООП, умные указатели, поиск пути BFS, CMake).

## Возможности

- **Пять уровней.** Карты лежат в `maps/level1.txt` … `maps/level5.txt` и подгружаются по очереди. Новый уровень можно добавить, не трогая код.
- **Лестница `>`.** Открывается, когда на уровне побеждены все враги. После пятого уровня игра выиграна.
- **Враги `M` со случайными характеристиками.** Они замечают игрока на расстоянии видимости, после чего преследуют его и находят путь в обход стен и сундуков (поиск в ширину, BFS).
- **Сундуки `C`.** Внутри случайные предметы. Если рюкзак полон, сундук не открывается.
- **Инвентарь.** Рюкзак игрока с ограничением по числу предметов. Зелья лечения и силы, на экране видны названия предметов.
- **Случайная расстановка.** Количество и положение врагов и сундуков выбираются случайно, но враги не появляются слишком близко к игроку.

## Управление

| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` | Движение. Шаг в сторону врага или сундука это удар или открытие |
| `1` | Использовать последний предмет из рюкзака |
| `Q` | Выход из игры |

## Обозначения

| Символ | Что это |
|---|---|
| `@` | Игрок |
| `M` | Враг |
| `C` | Сундук |
| `>` | Лестница на следующий уровень |
| `#` | Стена |
| `.` | Пол |

## Сборка и запуск

Нужны компилятор C++17 (например, GCC из MSYS2 UCRT64) и CMake.

```bash
git clone <ссылка-на-репозиторий>
cd roguelike
cmake -S . -B build
cmake --build build
build\roguelike.exe
```

> **Важно:** игру нужно запускать **из корня проекта**, иначе она не найдёт папку `maps/`. Если CMake не находит компилятор, добавь генератор: `cmake -S . -B build -G "MinGW Makefiles"`.

Проект работает только на **Windows**: ввод и очистка экрана используют `conio.h` и `system("cls")`.

## Свои уровни

Создай файл `maps/level6.txt` (следующий по номеру после последнего) и нарисуй карту символами `#`, `.` и `>`:

- все строки одной длины;
- по краям стены `#`;
- клетка `(1, 1)` должна быть полом: там появляется игрок;
- хотя бы одна клетка `>`.

Враги, сундуки и игрок расставляются автоматически.
## Настройка игры

Все числовые параметры собраны в `src/constants.h` (пространство имён `consts`). Их можно менять и пересобирать проект: здоровье и урон игрока, число и характеристики врагов, радиус видимости, количество сундуков, размер рюкзака, силу зелий и минимальное расстояние от игрока до места появления врагов.

## Структура проекта

| Файл | Содержимое |
|---|---|
| `src/main.cpp` | Точка входа |
| `src/game.h`, `src/game.cpp` | Игровой цикл, карта, загрузка уровней, расстановка, поиск пути |
| `src/entity.h`, `src/entity.cpp` | Базовый класс `Entity`, `Player`, `Enemy` |
| `src/chest.h`, `src/chest.cpp` | Сундуки |
| `src/item.h`, `src/item.cpp` | Предметы (`Item`, `HealPotion`, `PowerPotion`) |
| `src/constants.h` | Все числовые настройки игры |
| `maps/` | Файлы уровней |

## Использованные технологии и приёмы

- C++17, CMake
- Наследование и виртуальные методы (`virtual` / `override`) для врагов, сундуков и предметов
- `std::unique_ptr` для владения объектами
- `<random>` для генерации, `std::erase_if` и лямбды для очистки
- Поиск в ширину (BFS) на сетке с `std::queue`
- Чтение файлов (`std::ifstream`)
