# Roguelike

Консольный roguelike на C++ с ASCII-графикой. Мой первый проект на C++: игрок исследует карту, сражается с врагами и открывает сундуки с предметами. Находится в процессе развития

## Возможности

- Случайная расстановка врагов и сундуков при каждом запуске
- Бой: у игрока и врагов есть здоровье и урон
- Враги замечают игрока в пределах радиуса зрения и преследуют его
- Сундуки с предметами (лечебные зелья со случайной силой)
- Условия победы (все враги побеждены) и поражения (игрок погиб)
- Баланс игры настраивается в одном файле (`src/constants.h`)

## Управление

| Клавиша | Действие |
|---------|----------|
| `W` `A` `S` `D` | движение; шаг в сторону врага это атака, шаг в сторону сундука это открытие |
| `Q` | выход из игры |

Обозначения на карте:

| Символ | Что это |
|--------|---------|
| `@` | игрок |
| `M` | враг |
| `C` | сундук |
| `#` | стена |
| `.` | пол |

## Сборка и запуск

Требования: компилятор GCC с поддержкой C++20 (например, MSYS2 UCRT64) и CMake версии 3.20 или выше.

```
git clone <ссылка на репозиторий>
cd roguelike
cmake -S . -B build
cmake --build build
```

Запуск (из корня проекта):

```
build\roguelike.exe
```

> Игра рассчитана на **Windows**: для ввода используется `conio.h` (`_getch`), для очистки экрана `system("cls")`.

## Структура проекта

| Файл | Назначение |
|------|-----------|
| `src/main.cpp` | точка входа |
| `src/game.h`, `src/game.cpp` | игровой цикл, карта, отрисовка, расстановка объектов |
| `src/entity.h`, `src/entity.cpp` | базовый класс `Entity`, игрок (`Player`) и враги (`Enemy`) |
| `src/chest.h`, `src/chest.cpp` | сундуки (`Chest`) |
| `src/item.h`, `src/item.cpp` | предметы (`Item`, `HealPotion`) |
| `src/constants.h` | константы баланса |

## Что использовано

- ООП: наследование, виртуальные методы (`virtual` / `override`), полиморфизм
- Умные указатели (`std::unique_ptr`) и контейнеры (`std::vector`)
- Генерация случайных чисел через `<random>` (`std::mt19937`)
- Лямбда-выражения и `std::erase_if`
- Разделение кода на `.h` / `.cpp`, сборка через CMake
